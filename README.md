# CareerConnect – Job and Internship Platform

A web-based platform designed to connect students and job seekers with employers by providing a centralized place to explore job opportunities, discover internships, and apply for suitable positions.

## 📌 Project Overview

CareerConnect is a web application developed to simplify the job and internship search process for students and fresh graduates. It provides a user-friendly interface where users can explore career opportunities, filter listings, save interesting jobs, and apply by submitting their resumes.

The platform also allows employers to post job opportunities and helps organize the process of connecting candidates with relevant openings.

## 🎯 Objectives

* Centralize job and internship opportunities on one platform.
* Help students and fresh graduates discover career opportunities.
* Provide search and filtering options for job listings.
* Enable users to upload resumes and apply for opportunities.
* Allow employers to publish job openings.
* Maintain organized information using a MySQL database.

## ✨ Features

* **Job Listings:** Browse available job opportunities.
* **Internship Opportunities:** Explore internship listings.
* **Search and Filtering:** Find opportunities based on relevant criteria.
* **Resume Upload:** Upload a resume while applying for a job.
* **Job Application:** Apply for suitable opportunities.
* **Post a Job:** Provide a page for posting job opportunities.
* **Resources Page:** Access career-related resources.
* **Contact Page:** Find contact information and submit inquiries.
* **Login Page:** Access the platform's login interface.

## ⚙️ Installation and Setup

Follow these steps to run the project locally.

### Prerequisites

* XAMPP installed on your computer.
* A modern web browser.
* A code editor such as Visual Studio Code.

### Step 1: Clone the Repository

```bash
git clone https://github.com/darshana-2005/Career_Connect.git
```

### Step 2: Move the Project into XAMPP

Copy or extract the project folder into:

```text
C:\xampp\htdocs\
```

### Step 3: Start XAMPP

1. Open the XAMPP Control Panel.
2. Start **Apache**.
3. Start **MySQL** if your PHP application uses the database.

### Step 4: Configure the Database

1. Open phpMyAdmin at `http://localhost/phpmyadmin/`.
2. Create the MySQL database required by the project.
3. Import your SQL database file if one is included.
4. Update the database connection settings in the PHP files to match your local MySQL configuration.

*The database name, table structure, and connection settings should match your actual project files.*

### Step 5: Run the Application

Open your browser and visit:

```text
http://localhost/practice%20folder/
```

If you rename your project folder, replace `practice%20folder` with its new folder name.

## 💡 How It Works

1. Users open the platform and browse available job and internship opportunities.
2. They search or filter listings to find relevant openings.
3. Users can review opportunities and upload their resumes when applying.
4. The platform provides pages for saving jobs, accessing career resources, and contacting the platform.
5. Employers can use the job-posting interface to submit job opportunities.

The available workflows depend on the functionality implemented in the current project version.
